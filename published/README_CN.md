# Oblivious Sorting / Secure Sorting 论文包

本压缩包收录 2018–2025 年在 IEEE S&P、USENIX Security、ACM CCS、ASIACRYPT 和 EUROCRYPT 发表的 Oblivious Sorting、Secure Sorting 及其直接基础原语论文。

- `01_Core_Sorting/`：以 oblivious/secure sorting 为主要贡献的论文。
- `02_Related_Systems/`：将排序作为重要技术组件的系统或 FHE 工作。
- `03_Foundational_Primitives/`：compaction、ORAM、secret-shared shuffle 等直接基础工作。
- `download_report.tsv`：每篇论文的下载状态和实际来源。
- `SHA256SUMS.txt`：PDF 文件完整性校验值。
- `oblivious_sorting.bib`：BibTeX 条目。

所有 PDF 均从公开作者版本、IACR ePrint、USENIX Open Access、arXiv 或公开出版商链接下载，并在打包前验证 PDF 文件头和最小文件长度。若某篇论文没有可公开获取的 PDF，则对应目录中保留 `_NOT_DOWNLOADED.txt` 说明和出版商页面。
